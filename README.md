**Projeto Lista de Casamento**

O projeto tem como objetivo principal organizar a lista de casamento.

### Objetivo Principal:
- Organizar a lista de casamento.

### Objetivos Secundários:
- **Cadastrar presentes:**
  - Os noivos criam a lista de presentes.
- **Cadastrar convidados:**
  - Os noivos criam a lista de casamento.
- **Cadastrar acompanhantes:**
  - O convidado confirma sua presença no casamento.
  - O convidado pode escolher um presente e cadastrar os acompanhantes.

### Funcionalidades do Sistema:
- **Página "Home":**
  Na página principal, os noivos poderão:
  - Cadastrar os presentes, informando nome, foto, importância e preço estimado.
  - Visualizar uma lista de presentes cadastrados, com detalhes como nome, imagem, nível de importância e status de reserva (se já foi reservado, e por quem).
  - Acompanhar um gráfico mostrando a quantidade de presentes reservados e não reservados.

- **Página "Convidados":**
  Nesta página, os noivos poderão:
  - Cadastrar convidados, informando nome, WhatsApp e o número máximo de acompanhantes.
  - Visualizar uma lista de convidados, com informações como nome, status de confirmação de presença e um link único contendo um token para acesso à aplicação web destinada aos convidados.

- **Acesso dos Convidados:**
  Através do link fornecido, os convidados poderão:
  - Confirmar ou recusar sua presença no casamento.
  - Visualizar uma lista de presentes disponíveis, com detalhes como imagem, nome, nível de importância e um botão para reservar o presente. Ao clicar em "Reservar", o presente será associado ao nome do convidado e removido da lista disponível.
  - Cadastrar os acompanhantes, informando os nomes. Os convidados também poderão visualizar uma lista com os nomes de seus acompanhantes cadastrados.
